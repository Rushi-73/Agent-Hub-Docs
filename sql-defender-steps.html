Enable Defender for Azure SQL: Steps to Perform and Verify

Subscriptionba-ise-at33658-nch-preprod
Setting to changeDefender plan "Azure SQL Databases" (Microsoft.Security/pricings/SqlServers): Off (Free) to On (Standard)
ImpactApplies to all Azure SQL resources in the subscription. Changes only the Defender plan. No database, schema or data changes.
CostList price $15 per instance per month. Current count: 1 instance. Future Azure SQL resources in the subscription are also billed.
Required roleSecurity Admin, Contributor or Owner on the subscription

2. Steps to Perform

  1. In the Azure portal, go to Microsoft Defender for Cloud > Environment settings.
  2. Select the subscription ba-ise-at33658-nch-preprod.
  3. Select Defender plans.
  4. In the Cloud Workload Protection (CWPP) section, find the Databases row and select Select types.
  5. In the Resource types selection panel, set Azure SQL Databases to On. Leave the other three switches unchanged.
  6. Select Continue.
  7. Select Save at the top of the Defender plans page. The change is not applied until Save is selected.

3. Steps to Verify

A. Portal check

  1. Go to Defender plans and select Select types in the Databases row.
  2. Confirm Azure SQL Databases shows On.
  3. Confirm the Databases row shows Selected: 3/4.
[INSERT SCREENSHOT: Resource types selection panel, Azure SQL Databases = On (after change)]
[INSERT SCREENSHOT: Defender plans page, Databases row "Selected: 3/4" (after change)]

B. Tier check with Resource Graph Explorer (optional)

  1. In the portal search bar, open Resource Graph Explorer.
  2. Set the scope to ba-ise-at33658-nch-preprod and select Apply.
  3. Run this query:
    securityresources | where type == "microsoft.security/pricings" | project Plan = name, Tier = tostring(properties.pricingTier), Subscription = subscriptionId
  4. Confirm the row where Plan is SqlServers shows Tier = Standard. (Before the change it shows Free.)
[INSERT SCREENSHOT: Resource Graph query result, SqlServers = Standard]

C. Activity log check (optional)

  1. Open the subscription and select Activity log.
  2. Filter the operation for Update pricing (Microsoft.Security/pricings/write).
  3. Confirm there is a recent, successful entry.
